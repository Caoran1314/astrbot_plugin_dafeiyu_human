# 大肥鱼拟人管线

让机器人的回复像人在 QQ 上打字：会停顿、会分条、会打错字、不说 AI 腔

## 它解决什么问题

LLM 默认输出是「书面语 + 分点 + 句号」的客服腔，一眼假。这个插件在出站前做四件事：
1. 把 `，` 之后的断句拆成多条消息（像人一条一条发）
2. 禁掉冒号、破折号、句号（聊天里没人这么打字）
3. 按概率注入 0.6~4 秒延迟
4. 低概率打错字（默认 1%，短句不打）
另外内置一份「AI 腔黑名单」，把「有什么可以帮你的」「作为一个 AI」这类句子删掉。

## 安装

### 方式一：插件市场

在 AstrBot 面板 → 插件 → 插件市场 里搜索 `dafeiyu_human`。

### 方式二：手动

```bash
cd AstrBot/data/plugins
git clone https://github.com/Caoran1314/astrbot_plugin_dafeiyu_human
```

然后重启 AstrBot，或在面板里点「重载」。

## 配置

装好后在 面板 → 插件 → 大肥鱼拟人管线 → 配置 里调。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `delay_enable` | true | 是否加打字延迟 |
| `delay_min` / `delay_max` | 0.6 / 4.0 | 延迟区间（秒） |
| `max_chars` | 30 | 单条消息字数上限 |
| `typo_rate` | 0.01 | 错字概率 |
| `typo_min_chars` | 6 | 少于这个字数不打错字 |
| `banned_phrases` | 内置 | 额外要删掉的 AI 腔句子 |
